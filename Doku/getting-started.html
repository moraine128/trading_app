Schnellstart

In wenigen Schritten zum laufenden Trading-Bot

1. Installation

Repository klonen

git clone https://github.com/moraine128/trading_app.git
cd trading_app

Virtuelle Umgebung erstellen

# Windows
python -m venv venv
venv\Scripts\activate

# Linux/macOS
python3 -m venv venv
source venv/bin/activate

Dependencies installieren

Per requirements.txt installieren: 
pip install -r requirements.txt
Manuell bei Fehlern für Einzelpakete, diese Pakete nachinstallieren: 
pip install fastapi uvicorn pandas yfinance ta apscheduler jinja2 requests scikit-learn numpy plotly python-multipart optuna

2. Konfiguration

Erstelle config.json im Hauptverzeichnis:

{
  "trading": {
    "universes": ["DAX", "SP500"],
    "initial_capital": 10000,
    "max_positions": 10
  },
  "risk_management": {
    "take_profit_pct": 0.05,
    "stop_loss_pct": 0.03
  }
}

3. Server starten

uvicorn main:app --reload --host 0.0.0.0 --port 8000
✅ Erfolgreich! Öffne deinen Browser:
  • Dashboard: http://localhost:8000
  • API Docs: http://localhost:8000/docs
  • Dokumentation: http://localhost:8000/Doku

Häufige Probleme

Port bereits in Verwendung: 
uvicorn main:app --port 8001
