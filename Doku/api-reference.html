REST API Endpunkte und Verwendung

Base URL

http://localhost:8000

Endpunkte

POST /api/backtest

Backtest starten

POST /api/backtest
Content-Type: application/json

{
    "start_date": "2024-01-01",
    "end_date": "2025-12-31",
    "initial_capital": 10000,
    "universe": "DAX"
}
