Finde optimale Trading-Parameter mit Optuna

Optuna-Optimierung

Das System nutzt Optuna für automatische Hyperparameter-Optimierung.

Optimierbare Parameter

  • TAKE_PROFIT_PCT: Take-Profit Schwelle (0.01 - 0.15)
  • STOP_LOSS_PCT: Stop-Loss Schwelle (0.01 - 0.10)
  • TRAILING_STOP_ACTIVATION: Aktivierung Trailing Stop
  • MAX_TOTAL_POSITIONS: Max. Positionen (5-20)

Optimierung starten

import optuna

def objective(trial):
    take_profit = trial.suggest_float('take_profit', 0.01, 0.15)
    stop_loss = trial.suggest_float('stop_loss', 0.01, 0.10)

    result = run_backtest(take_profit, stop_loss)
    return result['total_return']

study = optuna.create_study(direction='maximize')
study.optimize(objective, n_trials=200)
