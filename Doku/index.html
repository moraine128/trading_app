Willkommen zur vollständigen Dokumentation des automatisierten Trading-Systems

Übersicht

Der Trading Bot ist ein umfassendes Python-basiertes System für algorithmisches Trading mit Fokus auf DAX und S&P 500 Aktien. Das System kombiniert technische Analyse, Machine Learning-Optimierung und Echtzeit-Datenverarbeitung.

ℹ️ Info: Diese Dokumentation richtet sich an Entwickler und fortgeschrittene Benutzer.

Hauptfunktionen

🔍 Technische Analyse

Umfassende Sammlung technischer Indikatoren inkl. RSI, MACD, Bollinger Bands, Moving Averages und mehr.

📊 Backtesting Engine

Robuste Backtesting-Engine zur Validierung von Handelsstrategien mit historischen Daten.

⚡ Optuna-Optimierung

Automatische Hyperparameter-Optimierung mit Optuna für optimale Trading-Parameter.

🌐 Web Dashboard

Interaktives FastAPI-basiertes Dashboard zur Überwachung und Steuerung des Trading-Bots.

📡 REST API

Vollständige REST API für programmatischen Zugriff auf alle Bot-Funktionen.

💾 Datenbank

SQLite-basierte Persistenzschicht für historische Daten und Trades.

Technologie-Stack

Backend

  • Python 3.13 - Hauptprogrammiersprache
  • FastAPI - Modernes Web-Framework
  • Pandas - Datenanalyse
  • NumPy - Numerische Berechnungen
  • yfinance - Echtzeit-Marktdaten
  • Optuna - Hyperparameter-Optimierung
  • SQLite - Datenbank
